## Последнее уточнение пользователя

Пользователь попросил сосредоточиться на результате и не тратить работу Codex
на предварительные расчёты расходов, сравнение цен и обсуждение экономии.

- Выполняй нужные JEV/DeepSeek-вызовы для фиксированного scope из 932 статей.
  Не начинай новую сессию оценки стоимости, не составляй предварительную смету
  и не запрашивай повторного общего разрешения на платные модели.
- Требования прежних промптов отдельно исследовать тарифы и рассчитывать смету
  перед запуском отменены этим уточнением. Используй подготовленный runner.
- Автоматический journal/usage сохраняй. В финале достаточно одной строки
  с фактическим записанным расходом; это оценка журнала, а не счёт провайдера.
- Не меняй уже frozen identity, не сбрасывай journal и не пересоздавай ревизию
  только ради другой бюджетной настройки. Существующие caps остаются технической
  конфигурацией запуска. Разбирай их только если они реально остановят работу;
  не трать время на гипотетическое превышение.
- Ограниченные retries, защита от повторной оплаты и остановка при unknown usage
  остаются: они нужны для корректного resume, а не для обсуждения экономии.
- Ограничения scope, качества, этапов и публикации сохраняются. Выполни расчёт,
  проверь `candidate.json`, сохрани handoff и передай этап 4. Не deploy/publish
  на этапе 3 и не анализируй весь текстовый корпус силами Codex.
